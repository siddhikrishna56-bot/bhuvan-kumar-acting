## 🚀 How to Host on GitHub Pages (Free Live URL)

1. Go to **[github.com/new](https://github.com/new)** and create a new repository named `bhuvan-kumar-acting` (set to **Public**).
2. Click **"uploading an existing file"** and drag-and-drop all files from this folder (`index.html`, `css/`, `js/`, `assets/`, `.nojekyll`, `.gitignore`, `README.md`).
3. Click **Commit changes**.
4. Go to **Settings > Pages > Branch: main / root > Save**.
5. Your website will be live at:
   `https://<your-username>.github.io/bhuvan-kumar-acting/`

## 📍 Adding to Google My Business (Google Business Profile)

1. Open **[Google Business Profile](https://www.google.com/business/)**.
2. Click **Edit profile** > **Business information** > **Contact**.
3. In **Website**, paste your live URL:
   `https://<your-username>.github.io/bhuvan-kumar-acting/`
4. In **Booking link**, paste:
   `https://<your-username>.github.io/bhuvan-kumar-acting/#booking`
5. Click **Save**.
